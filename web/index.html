Home Hider

Hide games, apps and system tiles from your home screen. Nothing is deleted, and you can show them again at any time.

Folders

Folders group games under one tile on your home screen. Press New folder to make one.

Check for updates when Home Hider starts
Looks on GitHub and on USB drives. Nothing is installed until you press Install.
Install from a file
Pick a HomeHider .elf on this phone or PC. To update from a USB drive instead, copy the .elf to the drive's top folder (or a folder named homehider) and press Check for updates.

"Refresh home screen now" restarts the home screen process. If it stays black for more than a few seconds, press the PS button or restart the console. "Restore original backup" puts back the database copy taken the first time Home Hider ran; games installed after that may need Safe Mode > Rebuild Database to reappear.
